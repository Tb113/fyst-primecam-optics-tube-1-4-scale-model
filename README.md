# FYST Prime-Cam Optics Tube Scale Model #
This project is a 1/4-scale, 3D-printed model of a detector module of the Fred Young Submillimeter Telescope's Prime-Cam instrument (FYST). 
  It depicts the three-lens design used by the 210, 280, 350, and 410 GHz modules 
  (The 850 GHz detector and Spectroscopic instruments use four lenses). The model is intended for educational and demonstrational use by 
  members of the CCAT collaboration for new collaborators, investors, and the general public. The fully assembled model can be contained 
  within a _x_x_ box, and the model includes a circular locking clip and stanchions to aid in storage and display.

## Included files ##
  The following files are included within the project:
#### .STL Files ####
  Six .stl files are included in total. These are organized by temperature stage/intended print color. All components in the files are aligned
  for proper printing. Although specifically constructed in Bambu Studio, the .STL files can be opened and processed with most commercial slicers.

#### .STEP File ####
  The .STEP file is a part file of the fully assembled three-Lens detector, meant to serve as a guide to assembling the printed components. 
  The file can be opened in most CAD programs, such as SolidWorks or Fusion (The original model was created in the former). Due to a limitation of
  the .STEP format, the color scheme is *not* depicted.

#### .PDF File ####
  The .PDF File serves as a more detailed guide to printing, assembling, and maintaining the model.
